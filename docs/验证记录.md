# move 1.2.0 验证记录

更新日期：2026-11-08（北京时间）。开发与测试环境：本机 Windows 11 64 位、Python 3.14。

## 本轮已完成的源码验证

- **核心测试 9 项通过。** 覆盖特殊字符密码和配置保存、原配置备份、外部修改冲突保护、CONFIG JSON 兼容、参数检查、模拟传输下的核心流程、失败日志与令牌隐藏、重复运行锁及时间格式处理。
- **界面交互测试 9 组通过。** 覆盖目标预览、显式保存及保存后运行、设置同步、账号操作、日志搜索和状态筛选、自动任务时间编辑与未保存修改保留、快速跳转，以及运行和停止状态反馈。
- **交互控件测试 6 组通过。** 验证目标刻度、数字变化和按钮反馈等控件的交互及生命周期。
- **浏览器宿主本地自检通过。** 使用本地测试页检查 JavaScript、localStorage 和 Blob 文件下载，不向原站提交生成请求。

目标刻度和大数字表示配置值。界面动画用于反馈操作或任务状态，不作为真实步数、运动完成率或平台同步进度的证据。

## 界面与交互范围

- 浅米白底色、鼠尾草绿与淡紫点缀，增加留白并简化布局；桌面内嵌浏览器工具栏与主窗口协调，原站网页保持原样。
- 调整目标刻度、移动滑块和点击预设仅更新目标预览，保存前不写入目标配置。
- 预览目标可单独保存，也可通过明确标注的“保存并运行”操作保存后执行。
- 未修改首页目标时，保留现有随机范围和按时间递增设置。
- 日志搜索和筛选只影响显示，完整记录与首页最近运行结果保留。
- 时间标签的添加、移除及文本编辑需要保存后生效；状态刷新保留未保存的修改。
- 页面切换、数字与运行状态反馈、Ctrl+K 快速跳转及较小窗口下的主要操作布局纳入界面检查。

## 运动轨迹模块的既有验证基线

1.1.0 版本已验证原站 https://sport.gyvv.top/ 与地图加载、Leaflet 初始化、地图瓦片、真实父子窗口关系、尺寸跟随、切走隐藏、返回恢复及关闭回收。
既有宿主测试也覆盖跨进程的 localStorage 持久化、Blob CSV 下载和同名文件保护。

当前使用 WebView2 SDK 1.0.4314.35；本机测试运行时为 157.0.4341.42。
网站页面没有 Python/.NET 对象桥，MiMotion 账号配置不传入网页。网站浏览器资料和导出文件保存在所选项目中。

## 发布验证与边界

1.2.0 新打包的 move.exe 已通过独立复核：清除 Python 路径后运行核心离线 worker；提取并启动 WebView2 宿主；加载原站与地图；保存网页渲染截图；关闭软件及宿主；提取后的组件完成 JavaScript、Blob 下载、localStorage 跨进程恢复和同名文件保护。共 8 组打包验收通过。

本次界面使用芙莉莲主题的浅色极简布局，Q 版头像由内置 image_gen 生成。PNG 保留透明 alpha，Windows ICO 来自同一 PNG 的格式转换，提示词见 assets/icon-prompt.txt。

测试使用独立目录与虚构账号，没有用真实账号提交步数，也没有创建、启停或改写用户现有的 Windows 自动任务。
未登录 Garmin、Zepp 或其他运动平台，未调用原站文件生成接口。
本地下载测试不证明原站每种格式的服务端生成始终可用；真实平台同步仍以实际执行和平台显示为准。
